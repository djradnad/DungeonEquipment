STAT FORMULAS

Formula reference

Base values at level 1: Equip D1 = 10.2%; Holding 1 D1 = 1.01%; Holding 2 S1 = 15.78125%; Holding 3 SS1 = 6.3125%.

Per-level growth: Equip ×1.02; Holding stats ×1.01.

Rank scaling: D–A use 5^tier × 1.5^(rank − 1); S uses 625 × 2^(rank − 1); SS is S4 × 2.5 then 2.5× per rank; SSS is SS4 × 12.5.

Holding stat 2 starts at S1; holding stat 3 starts at SS1.
